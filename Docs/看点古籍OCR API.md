**名词解释**

新增Token：新增API Token身份标识，每个Token为独立的，额度不共享；
Token：用户身份标识符，API接口为免登录的，需要通过Token进行标记，提高账户安全性；
状态：标明Token是否可用，分为：可用（审核通过）/不可用（待审核、审核不通过）；
统计：已使用次数和总次数，表示API Token的额度使用情况；
续加额度：可以给指定Token增加可用额度，更加方便实用；
