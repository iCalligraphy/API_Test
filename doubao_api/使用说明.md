# 书法单字分析工具 - 快速使用指南

## 最简单的使用方式

### 1. 确保环境配置正确

检查项目根目录的 `.env` 文件是否包含豆包API配置：
```
ARK_API_KEY="your-api-key-here"
ARK_VISION_MODEL="doubao-1.5-vision-pro-32k-250115"
```

### 2. 准备图片

将要分析的书法单字图片放入 `characters_test` 目录。

当前已有的图片：
- `州.png`
- `春.png`
- `雩.png`

### 3. 直接运行

```bash
cd doubao_api
python calligraphy_analyzer.py
```

就这么简单！程序会自动：
- ✅ 扫描 `characters_test` 目录下的所有图片
- ✅ 自动调整图片大小（确保边长>300px）
- ✅ 逐个调用豆包视觉模型分析
- ✅ 保存JSON结果到 `outputs` 目录
- ✅ 自动添加1.5秒延迟避免API限流

### 4. 查看结果

分析完成后，在 `outputs` 目录查看结果：
```
outputs/
├── 州_analysis_20241119_120000.json
├── 春_analysis_20241119_120002.json
└── 雩_analysis_20241119_120004.json
```

## 进阶用法

### 分析单个图片

```bash
python calligraphy_analyzer.py 永.png
python calligraphy_analyzer.py 永.png 永
python calligraphy_analyzer.py 永.png 永 output.json
```

### 可视化分析结果

```bash
python visualize_analysis.py 州.png outputs/州_analysis.json
```

这会生成：
- 标注了关键点的图片
- 包含详细信息的文字图片

## 常见问题

**Q: 运行提示"未找到 ARK_API_KEY"？**
A: 检查项目根目录的 `.env` 文件，确保配置了正确的API密钥。

**Q: 可以分析多少个字？**
A: 没有限制，但要注意API调用次数和费用。程序自动添加延迟避免限流。

**Q: 如果某个字分析失败怎么办？**
A: 程序会继续处理其他图片，最后显示成功/失败统计。

**Q: 坐标是什么意思？**
A: 使用相对坐标（0-1），表示关键点在图片中的相对位置。例如(0.5, 0.5)表示图片中心。

```
│   └── 雩.png

    ├── 春_analysis.json

```

## 提示

- 建议使用高清单字图片，效果更好
- 每次API调用都有费用，请合理使用
- 可以修改代码中的 `delay = 1.5` 来调整延迟时间
- 分析结果保存为JSON，便于后续程序化处理
